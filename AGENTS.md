# Project Guidelines

`Folder Structure:`

```
# Frontend application using Next.js
/apps/webapp
# Shared code including types, schemas, and utility functions
/packages/data-commons
```

`Tech Stack:`

- **Package Manager**: pnpm
- **Monorepo**: Turborepo
- **Frontend**: Next.js, React, Tailwind CSS, Shadcn UI, Zustand, React Hook Form, React Query, Zod
- **Shared**: TypeScript, Zod
- **Testing**: Vitest, React Testing Library
- **Database**: Prisma with PostgreSQL

---

## General Principles

- Respect existing patterns in the codebase
- Prioritize readability and maintainability
- Write explicit TypeScript types
- Follow SOLID principles
- Use functional programming and pure functions where appropriate
- Ensure accessibility (semantic HTML, ARIA, keyboard navigation)
